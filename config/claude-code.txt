# Claude Code MCP Configuration for xcodemcpwrapper
#
# To add xcodemcpwrapper to Claude Code, run:
#
#   claude mcp add --transport stdio xcode -- /Users/USERNAME/bin/xcodemcpwrapper
#
# Or add directly to Claude Code's MCP configuration:
#
#   claude mcp add xcode /Users/USERNAME/bin/xcodemcpwrapper
#
# Then verify it's loaded:
#
#   claude mcp list
#
# Note: Replace USERNAME with your actual username.
